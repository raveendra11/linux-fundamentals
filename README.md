# linux-fundamentals
   ## Commands:
         **basic**:
               **ls** - To list files or directories in a current directory.
               **ls -lrt** - To list files or directories with details (timestamp, user, permissions .. ) in a current directory.
               **cd** - To change from one to another directory.
               **mkdir** - To create/make a directory.
               **whoami** - To check current user.
               **pwd** - To check present working directory.
               **rmdir** - To delete an empty directory.
               **chmod** - To change permissions of files/directories.
               **chown** - To change ownership of files/directories.
               **rm** - To remove a file.
               **cp** - To copy files from one to other directory/copy files in same directory.
               **mv** - To move file/rename file.
